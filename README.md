# Seouri Tap

## How do I install these formulae?

`brew install seouri/tap/<formula>`

Or `brew tap seouri/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "seouri/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
